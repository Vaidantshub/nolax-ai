# Nolax AI — Algorithmic Quantitative Engine

A high-performance quantitative wealth management landing interface featuring real-time WebGL shaders, tactile physical buttons, and institutional financial ledgers.

## 🚀 Key Features

- **Procedural Day Azure Cloud Shader**: Ultra-optimized WebGL FBM cloud drift background with responsive DPR scaling.
- **Tactile Balloon Buttons**: Raymarched height-field cushion buttons with specular lighting, seam wrinkles, and rubber physics.
- **Acme-Style Traffic Overview**: Interactive monotone cubic spline chart with 7D, 30D, and 90D timeframes.
- **Thermal Dot-Matrix Receipts**: Authentic institutional paper slips with sawtooth tear perforations and dot-leader ledger specs.
- **Success Stories Marquee**: Infinite bidirectional testimonials loop with SVG vector emblems.
- **Mobile Drawer Navigation**: Responsive slide-down menu with touch-friendly navigation across all 6 core pages.

## 📁 Pages Included

- `index.html` — Main Landing Page
- `pricing.html` — Thermal Receipt Pricing & Comparative Architecture
- `services.html` — AI Market Radar & Execution Infrastructure
- `works.html` — Raw Audited Performance Ledger & Case Studies
- `about.html` — Philosophy, Institutional Team & Manifesto
- `contact.html` — Strategy Walkthrough Booking Desk

## ⚡ Deployment

This project uses a pure static architecture (HTML5 + CDN dependencies) with zero build steps required.

- **Vercel**: Pre-configured via `vercel.json` with clean URLs.
- **GitHub Pages**: Set Source to `Deploy from a branch` -> `main` / `/ (root)`.
- **Netlify**: Deploy directory `.`.
